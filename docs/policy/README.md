# LIVE:GUARD 정책 원본 (v3.2)

이 폴더가 LIVE:GUARD의 **정책 원본**이다. 다른 문서(계약 `contracts/openapi.yaml`, `docs/erd.md`, 이전 기획 `docs/live-guard/v0.3/`)와 충돌하면 이 폴더가 우선한다.
전체 우선순위는 [CLAUDE.md](../../CLAUDE.md)의 "기준 문서" 절을 따른다.

| 문서 | 내용 | 개정일 |
| --- | --- | --- |
| [PROJECT.md](PROJECT.md) | 공통 프로젝트 기준 | 2026-10-20 |
| [POLICY.md](POLICY.md) | 운영정책 및 제재 기준 | 2026-10-23 (v3.2) |
| [CONTRACTS.md](CONTRACTS.md) | 데이터와 인터페이스 계약 | 2026-10-20 |
| [ARCHITECTURE.md](ARCHITECTURE.md) | 시스템 아키텍처 | 2026-10-20 |
| [TBD-decisions.md](TBD-decisions.md) | 원본의 미정 항목(TBD-01~12) 결정안. 원본이 이미 정한 항목은 바꾸지 않는다 | 2026-10-23 |

- PROJECT·POLICY·CONTRACTS·ARCHITECTURE는 노션에서 내보낸 원문이다. 노션 페이지 제목 줄만 빼고 내용은 그대로 옮겼다.
- 정책을 바꿀 때는 이 폴더의 원본을 먼저 고치고, 계약(`openapi.yaml`)과 ERD는 그 뒤에 맞춘다.
